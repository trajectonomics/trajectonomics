> **อัปเดต: 24 พฤศจิกายน 2026** — ราคาและโควตาแพ็กเกจ AI เปลี่ยนเร็วมาก ตัวเลขในบทความนี้อ้างอิงจากหน้าผู้ให้บริการจริงและกราฟวัดผลของ [Pawel Huryn (วัด 19 พ.ย. 2026)](https://x.com/PawelHuryn/status/2125000511892099273) ราคาป้ายที่เป็นดอลลาร์สหรัฐแปลงเป็นบาทด้วยเรต **33.9 บาท/ดอลลาร์** (ปัดจากอัตราอ้างอิงของธนาคารแห่งประเทศไทยวันที่ 24 พ.ย. 2026 ที่ [33.9440 บาทต่อ 1 ดอลลาร์สหรัฐ](https://app.bot.or.th/BTWS_STAT/statistics/BOTWEBSTAT.aspx?language=eng&reportID=123)) แล้วปัดเป็นหลักสิบบาทเพื่อให้ตรงกับตัวเลขในคลิป (ไม่รวมภาษี) ส่วน **Google AI Pro** ใช้ราคาไทยจริงที่ **฿750/เดือน**

ในคลิปสั้นวันที่ 24 พ.ย. 2026 ผมชี้ให้ดูแค่ **3 งบหลัก** (`฿500`, `฿1,000`, `฿10,000`) เพราะเวลาในคลิปมีแค่ 13 วินาที บทความนี้คือ **Full List ครบทั้ง 5 ระดับ** — เพิ่มระดับ **งบ ฿5,000** (จุดคุ้มค่าสำหรับคนที่ทำงานจริงจัง) และ **ระดับองค์กร (Enterprise)** ที่ต้องใช้ API แทน Subscription พร้อมเหตุผลและตัวเลขจริงเบื้องหลังทุกบรรทัด

## ทำไม Subscription ส่วนบุคคลถึงคุ้มกว่าจ่าย API หลายสิบเท่า?

ก่อนลงรายละเอียดทีละงบ ดูกราฟที่ [Pawel Huryn (productcompass.pm)](https://x.com/PawelHuryn/status/2125000511892099273) วัดไว้เมื่อวันที่ **19–23 พ.ย. 2026** (ChatGPT Pro และ Muse วัด 1 ต.ค. 2026) โดยวัดโควตาจริงของแต่ละแพ็กเกจแล้วตีเป็นมูลค่าตามราคา API สาธารณะของแต่ละค่าย:

- **Claude Max (`$100/เดือน`, Fable 5.2 · Claude Code):** **27.3×** (`25.6–29.0×`, `≈ $1,360/เดือน` ของ Fable เพราะ Fable ใช้ได้สูงสุดครึ่งหนึ่งของโควตารายสัปดาห์)
- **Google AI Ultra (`$99.99/เดือน`, Gemini 4 Neon · Antigravity CLI):** **25.8×** (`25.3–26.3×`, `≈ $2,580/เดือน` — หมายเหตุบนกราฟว่าอาจสูงถึง `28–41×` เพราะ CLI นับ token ต่ำกว่าจริง 10–38%)
- **The X Subscription, Premium (`$30/เดือน`, Grok 4.7 · Grok Build):** **20.3×** (`20.1–20.5×`, `≈ $610/เดือน` ที่ low effort; `≈ 20–26×` บนงาน agent ระดับ xhigh)
- **GLM Coding Plan Pro (`$80/เดือน`, GLM-5.3 · Claude Code):** **10.4×** (`≈ $830/เดือน`)
- **ChatGPT Pro (`$100/เดือน`, GPT-6.1 Sol · Codex CLI):** **10.25×** (`≈ $1,025/เดือน`, วัด 1 ต.ค.)
- **Muse Code High Usage (`$15/เดือน`, Muse Spark 1.3 · Muse Code):** **9.3×** (`≈ $140/เดือน`, วัด 1 ต.ค.)

สรุปสั้น ๆ คือ **ถ้าคุณเป็นผู้ใช้งานรายบุคคล การสมัคร Subscription ได้ส่วนลดแฝงจากผู้ให้บริการถึง 10–46 เท่า** เทียบกับการเติมเงิน API เอง — แต่พอขยับเป็นองค์กรที่ไม่สามารถแชร์บัญชีรายบุคคลได้ เกมจะเปลี่ยนไปเป็นการเลือกราคา API แทนทันที

## 1. งบ ฿500/เดือน — OpenCode Go (`$10 ≈ ฿340`)

ถ้ามีงบไม่เกิน 500 บาทต่อเดือน ตัวที่คุ้มที่สุดสำหรับสายเขียนโค้ดและรันเอเจนต์คือ **[OpenCode Go](https://opencode.ai/console/go)** ราคาป้าย **$10/เดือน** (`10 × 33.9 = ฿339` ปัดเป็น **฿340**)

ตามตารางโควตาทางการบนหน้า [OpenCode Go](https://opencode.ai/console/go) และ [เอกสาร Go](https://opencode.ai/docs/console/go/) แพ็กเกจ `$10` ให้มูลค่าการใช้งานรายเดือน (กรณีใช้โมเดลนั้นตัวเดียวตลอดทั้งเดือน) สูงกว่าค่าสมาชิกราว **10–20 เท่า** โดยเฉพาะ 2 ตัวหลักที่ผมแนะนำให้โฟกัส:

- **DeepSeek V4.1 Flash:** โควตารายเดือนเทียบเท่า **`$100`** (`100 × 33.9 = ฿3,390`, ประมาณ 43,300 requests ต่อหน้าต่าง 5 ชม.) — คุ้ม **10×**
- **GLM-5.3:** โควตารายเดือนเทียบเท่า **`$200`** (`200 × 33.9 = ฿6,780`, ประมาณ 2,640 requests ต่อหน้าต่าง 5 ชม.) — คุ้ม **20×**

**ข้อควรรู้จากเอกสารทางการของ OpenCode Go:**
- โมเดลเสียเงินทั้งหมดแชร์โควตารวมก้อนเดียวกัน (สลับใช้หลายตัวจะหักสัดส่วนจากกองเดียวกัน)
- มีเพดานย่อย `20% ต่อหน้าต่าง 5 ชั่วโมง` และ `50% ต่อสัปดาห์` (รีเซ็ตวันจันทร์ 00:00 UTC) ถ้าใช้ครบเพดานสามารถใช้โมเดลฟรีใน OpenCode ต่อได้
- การเปิดใช้ DeepSeek V4.1 Flash ต้องตั้งค่า Regions เป็น `Global` ใน `Settings › Privacy`

## 2. งบ ฿1,000/เดือน — Google AI Pro (`฿750`)

ขยับมางบ 1,000 บาท ตัวที่ครบเครื่องที่สุดในราคา **฿750/เดือน** (ราคาไทยบน [Google AI Plans](https://one.google.com/intl/th_th/about/google-ai-plans/), สหรัฐฯ `$19.99/เดือน` บน [US Plans](https://one.google.com/intl/en_us/about/google-ai-plans/)) คือ **Google AI Pro**

สิ่งที่คุณได้จริงในงบ ฿750 แบ่งเป็น 3 ก้อน:

1. **โควตา Gemini 4 Neon ประเมินมูลค่า API สูงสุด ~฿17,490/เดือน (`~$516`):**
   - ตัวเลขนี้มาจากการคำนวณที่ตรวจซ้ำได้: ในกราฟของ [Pawel Huryn](https://x.com/PawelHuryn/status/2125000511892099273) แผน **Google AI Ultra (`$99.99/เดือน`)** วัดได้ `25.8×` หรือ **`≈ $2,580/เดือน`** ตามราคา API ของ [Gemini 4 Neon](https://aistudio.google.com/docs/pricing) (`$3.00 / 1M input` และ `$15.00 / 1M output`)
   - หน้าแพ็กเกจทางการของ Google ระบุว่าแผน Ultra ได้ขีดจำกัดการใช้งาน Gemini สูงกว่าแผน AI Pro **5 เท่า** (`5× higher usage limits in Gemini than the AI Pro plan`)
   - เมื่อหาร 5 จึงได้ส่วนแบ่งของ Google AI Pro อยู่ที่ **`$2,580 ÷ 5 = $516/เดือน`** (`516 × 33.9 = 17,492.4 → ~฿17,490/เดือน`) *(หมายเหตุ: นี่คือการประมาณตามสัดส่วน 5× ไม่ใช่การวัดตรงบนแผน Pro และจำนวน token จริงขึ้นกับสัดส่วน input/output)*
2. **สร้างภาพไม่จำกัด + วิดีโอสูงสุด 13 นาที 53 วินาที/เดือน:**
   - แผน Google AI Pro ให้เครดิต [Google Flow](https://one.google.com/intl/th_th/about/google-ai-plans/) **1,000 เครดิต/เดือน** บวกกับเครดิตฟรีรายวัน **50 เครดิต/วัน** ที่ทุกบัญชีได้รับ ([Google Flow Help](https://support.google.com/flow/answer/16526234?hl=en), ไม่ทบข้ามวัน) — ถ้าใช้ครบทุกวันใน 30 วันจะมี `1,000 + (50 × 30) = 2,500 เครดิต/เดือน`
   - โมเดลสร้างวิดีโอ **Gemini Omni 1.2 Flash ที่ 720p** ใช้ `3 เครดิต/วินาที` → `2,500 ÷ 3 = 833.33 วินาที` = **13 นาที 53 วินาที** ส่วนการสร้างภาพนิ่งไม่เสียเครดิต
3. **ของแถมใช้งานจริงทุกวัน:** พื้นที่เก็บข้อมูลคลาวด์ **5 TB** (Gmail, Drive, Photos) และ **YouTube Premium Lite** รวมอยู่ในแพ็กเกจ

**Gemini 4 Neon vs Claude Opus 5.5 จากประสบการณ์ใช้งานจริง:**
ในการใช้งานทั่วไปและการเขียนโค้ด **Gemini 4 Neon เก่งสูสีกับ Claude Opus 5.5 มาก** จุดที่ Opus 5.5 ยังเหนือกว่าอยู่เล็กน้อยคือความอึดใน **งานรันยาวแบบอัตโนมัติ (long-running autonomous task)** — แต่ข้อได้เปรียบที่ชัดเจนของ Google AI Pro คือ **ได้ทั้งสร้างภาพและวิดีโอมาครบในแพลนเดียว** ในขณะที่ฝั่ง Claude ไม่มี

*(หากต้องการเทียบทางเลือกงบ 1,000 บาทแบบแยกทีละงาน เขียนโค้ด / เอเจนต์ / ครีเอทีฟ อ่านเพิ่มได้ที่ [งบ 1,000 บาท Subscribe อะไร?](/th/guides/ai-subscribe-1000-baht/))*

## 3. งบ ฿5,000/เดือน — Claude Max + Google AI Pro (`฿4,140`)

*ระดับนี้ไม่ได้อยู่ในคลิป 13 วินาที แต่เป็นคู่ที่ผมมองว่าคุ้มและสมดุลที่สุดสำหรับคนที่ทำงานกับ AI ทุกวัน:*

- **[Claude Max](https://claude.com/pricing) (`$100/เดือน ≈ ฿3,390`):** ได้โควตา **5× ของ Pro** ทั้งรอบ 5 ชั่วโมงและรายสัปดาห์ รวม Claude Code, ใช้ Fable 5.2 ได้สูงสุดครึ่งหนึ่งของโควตารายสัปดาห์ และมี **API credits `$100/เดือน`** แถมมาให้ด้วย
  - จากกราฟของ [Pawel Huryn](https://x.com/PawelHuryn/status/2125000511892099273) แผนนี้คือ **แชมป์ตัวคูณความคุ้มค่าที่ `46.4×`** (`≈ $4,640/เดือน` หรือ `4,640 × 33.9 ≈ ฿157,300/เดือน` บน Opus 5.5) — สูงกว่าทุกค่ายในตลาดชัดเจน
- **[Google AI Pro](https://one.google.com/intl/th_th/about/google-ai-plans/) (`฿750/เดือน`):** มาอุดช่องว่างเรื่องภาพและวิดีโอที่ฝั่ง Claude ไม่มี พร้อมพื้นที่ 5 TB, YouTube Premium Lite และโมเดล Gemini 4 Neon ไว้สลับใช้งาน

**จ่ายรวม:** `฿3,390 + ฿750 = ฿4,140/เดือน` (เหลือทอนเกือบ 900 บาทจากงบ ฿5,000) ได้ทั้งตัวท็อปงานรันยาว (Opus 5.5) และตัวท็อปสายครีเอทีฟ/ภาพ/วิดีโอ (Google AI Pro) ครบในคู่เดียว

## 4. งบ ฿10,000/เดือน — ชุดเต็ม 4 แพลน (`฿9,230`)

สำหรับคนที่รัน coding agent หนักทั้งวันข้ามคืนและต้องการระบบ **cross-model review** (ให้โมเดลต่างค่ายช่วยตรวจงานกันเอง) นี่คือชุดเต็มที่ผมใช้จริงในงบไม่เกิน 10,000 บาท:

| แพลน | ราคาป้าย | เป็นบาท (เรต 33.9) | บทบาทในสแต็ก |
| --- | --- | --- | --- |
| **[Claude Ultra](https://claude.com/pricing)** | `$200/เดือน` | **฿6,780** | โมเดลหลักรันงานยาว — โควตา **10× Pro รายสัปดาห์**, **ไม่มีลิมิต 5 ชม.** (สำหรับบัญชีที่ยืนยันแล้ว) และ API credits `$200/เดือน` |
| **[Google AI Pro](https://one.google.com/intl/th_th/about/google-ai-plans/)** | ฿750/เดือน | **฿750** | สร้างภาพ/วิดีโอ (Flow), 5 TB, YouTube Premium Lite และ Gemini 4 Neon |
| **The X Subscription (Premium)** | `$30/เดือน` | **฿1,020** | Grok 4.7 + Grok Build (กราฟ Huryn วัดได้ **20.3×** หรือ `≈ $610 ≈ ฿20,680/เดือน` ที่ low effort) และสิทธิ์ X Premium+ |
| **[ChatGPT Plus](https://chatgpt.com/pricing)** | `$20/เดือน` | **฿680** | **Cross-model reviewer** — เอาตระกูล GPT มาตรวจโค้ด ตรวจแผน และจับจุดบอดของงานที่ Claude เขียน |
| **รวมทั้งหมด** | `$250 + ฿750` | **฿9,230/เดือน** | อยู่ในงบ ฿10,000 |

**ตัวเลข "Ultra ได้สูงสุด ฿315,000" ในคลิปมาจากไหน?**
กราฟของ Pawel Huryn วัดตัวคูณ `46.4×` บนแผน **Claude Max (`$100`)** — บนคลิปเราตั้ง **สมมติฐานว่า Claude Ultra (`$200`) มีตัวคูณเท่ากันที่ `46.4×`** จึงคำนวณได้ `$200 × 46.4 = $9,280/เดือน` หรือ `9,280 × 33.9 = ฿314,592` (ปัดเป็น **~฿315,000/เดือน**) ตัวเลขนี้เป็นสมมติฐานจากตัวคูณของ Max ไม่ใช่ค่าที่ Huryn วัดแยกบนแผน Ultra โดยตรง (และยังไม่นับ API credits `$200/เดือน` ที่แถมในแผน)

## 5. ระดับองค์กร (Enterprise) — จ่ายผ่าน API: GPT เป็นหลัก + Claude เฉพาะงานที่ยากที่สุด

*ระดับนี้เป็นอีกชั้นที่เพิ่มไว้ในบทความโดยเฉพาะ เพราะกติกาฝั่งองค์กรต่างจากผู้ใช้ทั่วไปโดยสิ้นเชิง:*

**ทำไมองค์กรต้องใช้ API แทน Subscription?**
แพ็กเกจรายเดือนแบบบุคคลถูกออกแบบมาสำหรับคนเดียว มีลิมิตราย 5 ชม./รายสัปดาห์ แชร์ใช้ในระบบอัตโนมัติหรือ CI/CD ระดับบริษัทไม่ได้ และองค์กรมักต้องการสัญญาคุมข้อมูล (Zero Data Retention / DPA), การแยกบิลตามทีม และสิทธิ์การเข้าถึงแบบรวมศูนย์ — นั่นแปลว่า **องค์กรต้องจ่ายตามจริงในราคา API** ซึ่งไม่มีตัวคูณ `20×–46×` เหมือนฝั่งบุคคลอีกต่อไป

เมื่อต้องจ่ายราคา API เต็มเม็ดเต็มหน่วย ตารางราคาสาธารณะต่อ 1 ล้าน token ณ วันที่ 25 พ.ย. 2026 อธิบายชัดทันทีว่าทำไมกลยุทธ์จึงเปลี่ยน:

| โมเดล (ลิงก์หน้าราคาทางการ) | Input / 1M | Cached / 1M | Output / 1M |
| --- | --- | --- | --- |
| **[GPT-6.2 Sol](https://developers.openai.com/api/docs/pricing)** | **$2.00** | **$0.10** | **$10.00** |
| **[Gemini 4 Neon](https://aistudio.google.com/docs/pricing)** | **$3.00** | **$0.15** | **$15.00** |
| **[Claude Opus 5.5](https://platform.claude.com/docs/en/about-claude/pricing)** | **$4.00** | **$0.20** | **$20.00** |
| **[Claude Fable 5.2](https://platform.claude.com/docs/en/about-claude/pricing)** | **$8.00** | **$0.20** | **$40.00** |

**สูตรจัดทัพ API สำหรับองค์กร:**
1. **งานส่วนใหญ่ประจำวัน → ส่งให้ GPT (`GPT-6.2 Sol`):** ราคา API ถูกกว่า Claude Opus 5.5 **ครึ่งหนึ่งทุกช่อง** (`$2/$10` เทียบกับ `$4/$20`) และถูกกว่า Fable 5.2 ถึง **4 เท่า** แถมบนกราฟ [Artificial Analysis](/th/guides/ai-model-tier-breakdown/) ยังอยู่กลางโซนคุ้มค่าที่สุด (`~$1/task` เทียบกับ Opus 5.5 ที่ `~$10/task`) ใช้คุมงานฟีเจอร์ประจำวัน รีวิว PR และ pipeline อัตโนมัติได้โดยไม่เผาเงิน
2. **เฉพาะโจทย์ที่ยากที่สุด → ค่อยส่งให้ Claude (`Opus 5.5` หรือ `Fable 5.2`):** เก็บ Claude ไว้สำหรับงานออกแบบสถาปัตยกรรมที่ซับซ้อน บั๊กเรื้อรัง หรือ agent ที่ต้องคิดต่อเนื่องยาว ๆ จุดที่ความแม่นยำและความอึดช่วยประหยัดเวลาวิศวกรได้คุ้มค่ากว่าส่วนต่างราคา token
