ผมเชื่อว่างาน Software Engineering ในอนาคตจะย้ายจากการนั่งพิมพ์โค้ดหน้าคอมตลอดเวลา ไปสู่การสั่งงานและตรวจงานผ่านแชตแอป (Slack, Discord) หรือแอปบนมือถือมากขึ้นเรื่อย ๆ ไม่ใช่เพราะคอมพิวเตอร์จะหายไป — งานที่ต้องดูรายละเอียดเยอะ ๆ นั่งหน้าจอยังสบายกว่า — แต่เมื่อ AI coding agent รันงานหนึ่งรอบกินเวลา 1–2 ชั่วโมง เราไม่ควรต้องนั่งเฝ้าหน้าจอ 2 ชั่วโมงเพื่อรอมันเสร็จ

โพสต์นี้คือสรุป Setup จริงที่ผมใช้เขียนโค้ดจากมือถือทุกวัน เปรียบเทียบกับทางเลือกอื่นที่มีอยู่ในตลาดตอนนี้ อธิบายว่าทำไมผมเลือก self-host **T3 Code + Tailscale** และวิธีตั้งค่าเองตั้งแต่เครื่องเดียว

## 4 วิธีที่คนนิยมใช้เขียนโค้ดจากมือถือตอนนี้

การคุม coding agent จากมือถือไม่มีวิธีเดียว แต่ละแบบเหมาะกับเงื่อนไขต่างกัน:

| วิธี | หลักการทำงาน | จุดเด่น | ข้อจำกัดที่ควรรู้ |
| --- | --- | --- | --- |
| **1. Cloud VPS + SSH** | เช่า VM บน cloud แล้วต่อ SSH หรือรัน web terminal จากมือถือ | ออนไลน์ 24 ชม. ไม่ต้องมีเครื่องที่บ้าน ปรับแต่งได้อิสระเต็มที่ | เสียค่าเช่าเครื่องรายเดือน ยิ่งรันหลาย repo/build หนัก RAM ยิ่งแพง และพิมพ์ใน terminal บนจอมือถือใช้งานยากกว่า UI ที่ทำมาเพื่อ agent |
| **2. [Google Antigravity](https://antigravity.google)** | ใช้ฟีเจอร์ Remote Control คุมเครื่องเดสก์ท็อปผ่านเบราว์เซอร์มือถือ หรือใช้ Remote Agents บน cloud VM ของ Google | ตั้งค่าง่ายมาก แทบไม่ต้องยุ่งเรื่องเครือข่าย มีทั้งโหมดคุมเครื่องที่มีแอปเดสก์ท็อปและโหมด cloud VM ของ Google | โฟกัสอยู่ใน ecosystem ของ Antigravity ถ้าคุณมี subscription AI หลายค่ายและอยากคุมรวมในหน้าจอเดียวจะยังไม่รวมศูนย์ |
| **3. [Orca (Stably AI)](https://github.com/stablyai/orca)** | Open-source (MIT) รันหลาย agent แยก git worktree พร้อมแอปมือถือ iOS/Android และ remote runtime ผ่าน SSH | มีแอปมือถือ iOS/Android + push notification รองรับหลาย CLI agent | โฟกัสการจัดการแต่ละ CLI agent/worktree ผ่านแอปคู่หูของ Orca เอง |
| **4. [T3 Code](https://t3.codes) + [Tailscale](https://tailscale.com)** | Self-host T3 Code บนเครื่องของเราเอง แล้วเชื่อมทุกเครื่องกับมือถือในวง VPN ส่วนตัวผ่าน Tailscale | รวม subscription AI หลายเจ้าในหน้าจอเดียว เชื่อมคอมหลายเครื่องเข้าด้วยกัน ไม่มีค่าเช่า cloud รายเดือน | ต้องตั้งค่าเครือข่ายด้วย Tailscale และมีเครื่องที่เปิดออนไลน์ไว้ |

## ทำไมผมเลือก self-host T3 Code บนคอม 3 เครื่อง

หลังจากลองใช้งานจริงในงานประจำและโปรเจกต์ส่วนตัว นี่คือเหตุผลที่ผมลงตัวกับ **T3 Code + Tailscale**:

1. **รวม Subscription หลายเจ้าไว้ในหน้าจอเดียว:** ผมไม่ได้ผูกกับโมเดลเจ้าเดียว แต่สลับใช้ตามความถนัดของงาน (เช่น Claude, Codex, Gemini/Antigravity, OpenCode) ใน [T3 Code](https://github.com/pingdotgg/t3code) ผมเปิด thread แยกตาม repo และเลือก provider ได้จาก UI เดียวบนมือถือ ไม่ต้องสลับหลายแอปหรือสลับหน้าต่าง SSH
2. **เชื่อมคอม 3 เครื่องเป็นพื้นที่ทำงานเดียว:** Setup จริงของผมประกอบด้วย **โน้ตบุ๊ก 1 เครื่อง** (สำหรับนั่งทำงานจริงจังตอนอยู่โต๊ะ) และ **Home Server 2 เครื่อง** (คอมเก่าและ mini PC ที่เสียบสาย LAN ทิ้งไว้ที่บ้าน) ผ่านฟีเจอร์ Linked Environments บนมือถือผมจึงเลือกได้ทันทีว่าจะเปิด thread บนเครื่องไหน
3. **ไม่ต้องเปิดโน้ตบุ๊กทิ้งไว้ และไม่เสียค่า Cloud รายเดือน:** เมื่อปล่อย agent รันยาว 2 ชั่วโมง งานจะวิ่งอยู่บน Home Server ที่บ้าน โน้ตบุ๊กพับเก็บได้ แบตไม่หมด และไม่มีบิลค่าเช่า VM ต่อชั่วโมง
4. **ไม่เปิดพอร์ตออกอินเทอร์เน็ตสาธารณะ:** ทุกเครื่องกับมือถือเชื่อมกันผ่าน [Tailscale](https://tailscale.com) (Mesh VPN บน WireGuard) เฉพาะอุปกรณ์ที่ล็อกอินบัญชีของเราเท่านั้นที่มองเห็นกัน ไม่ต้องทำ port forwarding บนเราเตอร์ที่บ้าน

## Workflow จริงในหนึ่งวัน

- **ระหว่างเดินทางไป–กลับที่ทำงาน:** เปิด T3 Code บนมือถือ อ่านสรุปงานที่ agent ทำค้างไว้ ตอบคำถามที่ต้องให้คนตัดสินใจ หรือสั่งเปิดงานใหม่
- **งานยาว 1–2 ชั่วโมง:** ปล่อย agent รันบน Home Server แล้วออกไปกินข้าว ไปยิม หรือออกไปเที่ยว ปล่อยให้เครื่องที่บ้านรัน test และเปิด PR รอไว้
- **ตอนกลับมาอยู่หน้าโต๊ะ:** กลับไปนั่งโน้ตบุ๊กเพื่อรีวิว diff ใหญ่ ๆ ตรวจหน้าตา UI หรือวางสถาปัตยกรรม คอมพิวเตอร์ไม่ได้หายไปไหน แค่ Setup นี้คืน **flexibility** ให้เราไม่ต้องติดอยู่หน้าจอตลอดเวลา

## วิธีตั้งค่าเองทีละขั้น (มีคอมเครื่องเดียวก็เริ่มได้)

คุณไม่จำเป็นต้องซื้อ Home Server ตั้งแต่วันแรก เริ่มจากคอมหรือโน้ตบุ๊กที่มีอยู่เครื่องเดียวก่อนได้เลย:

### ขั้นที่ 1: เชื่อมคอมกับมือถือด้วย Tailscale

1. ติดตั้ง [Tailscale](https://tailscale.com/download) ทั้งบนคอมพิวเตอร์และบนมือถือ (iOS / Android)
2. ล็อกอินด้วยบัญชีเดียวกันทั้งสองเครื่อง
3. ตรวจสอบว่าอุปกรณ์ทั้งสองขึ้นสถานะเชื่อมต่อกันในหน้า Tailscale — แค่นี้มือถือก็เรียกหาคอมที่บ้านได้จากทุกที่ (4G/5G หรือ Wi-Fi นอกบ้าน) โดยไม่ต้องเปิดพอร์ตเราเตอร์

### ขั้นที่ 2: ติดตั้ง T3 Code บนคอมที่จะรันงาน

1. ติดตั้งและรัน [T3 Code](https://github.com/pingdotgg/t3code) บนเครื่องที่ต้องการให้รัน agent (ดูคู่มือติดตั้งล่าสุดที่ [t3.codes](https://t3.codes))
2. ผูก CLI / AI coding agent ที่คุณมี subscription อยู่แล้วในเครื่องนั้น และเพิ่มโฟลเดอร์โปรเจกต์ (Git repository) ที่ต้องการทำงานด้วย
3. ตั้งค่าให้ T3 Code เปิดรับการเชื่อมต่อผ่านเครือข่าย Tailscale ของคุณ (อย่าเปิดรับจากอินเทอร์เน็ตสาธารณะโดยไม่ผ่าน VPN)

### ขั้นที่ 3: เปิดใช้งานจากมือถือ

1. เปิดแอป Tailscale บนมือถือให้ทำงานอยู่
2. เปิดเบราว์เซอร์บนมือถือไปยังที่อยู่ Tailscale ของเครื่องที่รัน T3 Code (แล้วกด Add to Home Screen เพื่อใช้งานเหมือนแอป)
3. ถ้ามีหลายเครื่อง (เช่น โน้ตบุ๊ก + Home Server) ให้เชื่อม Linked Environments เข้าหากัน จะได้เห็นทุกเครื่องและทุก thread ในรายการเดียว

### ขั้นที่ 4: ตั้งรั้วความปลอดภัยก่อนปล่อย Agent รันยาว

การสั่งงานจากมือถือจะได้ผลดีก็ต่อเมื่อคุณไว้ใจได้ว่า agent จะไม่ทำโปรเจกต์พังระหว่างที่คุณไม่ได้อยู่หน้าจอ:

- **แยก Git Worktree / Branch เสมอ:** ให้แต่ละ thread ทำงานบน branch แยก ห้ามแก้ตรงบน `main`
- **มีคำสั่ง Check อัตโนมัติ:** ตั้งคำสั่งตรวจ (lint, typecheck, test) ให้ agent รันจนเขียวก่อนรายงานว่าเสร็จ
- **คุมสิทธิ์การอนุมัติ:** งานที่แตะโครงสร้างสำคัญหรือย้อนกลับยากให้ตั้งค่าขออนุมัติก่อนเสมอ

### ขั้นที่ 5: ขยับไปใช้ Home Server (เมื่อเริ่มใช้งานจริงจัง)

เมื่อเริ่มปล่อย agent รันบ่อยขึ้น ค่อยเอาคอมเก่าหรือ mini PC ที่ไม่ได้ใช้แล้วมาลง Linux เสียบสาย LAN ไว้ที่บ้าน แล้วลง Tailscale + T3 Code แบบเดียวกับขั้นที่ 1–2 คุณก็จะได้เครื่องที่พร้อมรันงานตลอด 24 ชั่วโมงโดยไม่ต้องเปิดโน้ตบุ๊กทิ้งไว้
