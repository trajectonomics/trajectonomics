# MooJot

A free, open-source money tracker for Thai bank slips, and an alternative to Meowjot. MooJot is not affiliated with or endorsed by Meowjot or any bank.

Website and download: https://moojot.trajectonomics.com (source in [`site/`](site/README.md)).

Terms: [docs/terms-of-service.md](docs/terms-of-service.md). Privacy policy: [docs/privacy-policy.md](docs/privacy-policy.md). Android releases: [docs/release/android.md](docs/release/android.md).
