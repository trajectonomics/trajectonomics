ติดตั้งInstall

ติดตั้งใน 3 ขั้นตอนInstall in 3 steps

OpenJot ยังไม่อยู่บน Play Store เลยติดตั้งจากไฟล์ APK แทน ใช้เวลาไม่ถึงนาที

OpenJot isn't on the Play Store yet, so you install the APK file directly. It takes under a minute.

ดูวิดีโอสอนติดตั้งWatch the tutorial video
  1. 1

    ดาวน์โหลดไฟล์Download the file

    แตะปุ่มดาวน์โหลด ถ้า Chrome ขึ้นว่า “ไฟล์นี้อาจเป็นอันตราย” ให้แตะ “ดาวน์โหลดต่อ” ไฟล์มาจากหน้า Releases บน GitHub ของโปรเจกต์โดยตรง

    Tap the download button. If Chrome says the file might be harmful, tap “Download anyway”. It comes straight from the project's GitHub releases.

    ดาวน์โหลด APKDownload APK เร็วๆ นี้Coming soon
  2. 2

    อนุญาตให้ติดตั้งAllow the install

    แตะไฟล์ที่โหลดเสร็จ ถ้า Android ไม่ให้ติดตั้งแอปที่ไม่รู้จัก แตะ “การตั้งค่า” → เปิด “อนุญาตจากแหล่งที่มานี้” → กลับมาแตะ “ติดตั้ง”

    Open the finished download. If Android blocks unknown apps, tap Settings, turn on “Allow from this source”, then go back and tap Install.

    ถ้า Play Protect เตือน แตะ “รายละเอียดเพิ่มเติม” → “ติดตั้งต่อไป”

    If Play Protect warns you, tap “More details” → “Install anyway”.

  3. 3

    เปิดแอป ให้มูอ่านสลิปOpen it and let Moo read

    อนุญาตให้ OpenJot เข้าถึงรูปภาพ แล้ว ดึงหน้าแรกลง มูจะอ่านสลิปจากอัลบั้มของแอปธนาคารแล้วจดให้ครบ ไม่ต้องใช้อินเทอร์เน็ต

    Allow OpenJot to see your photos, then pull down on the home screen. Moo reads the slips in your banking apps' albums and logs them, with no internet needed.

อัปเดต: โหลดไฟล์ใหม่จากหน้านี้แล้วติดตั้งทับได้เลย ข้อมูลเดิมอยู่ครบ เพราะทุกเวอร์ชันเซ็นด้วยคีย์เดียวกัน

Updating: download the new file from this page and install it over the old one. Your records stay, because every release is signed with the same key.

Want to check the file? Every release ships a SHA256SUMS file and is signed with the project's key, CN=MooJot (the app's earlier name), SHA-256 fingerprint be15a0f5b17358990cecde23d3c49dc02a1741ee544006ac5b0114755041a3a1. Don't install an OpenJot APK whose fingerprint is different.

ฟีเจอร์Features

มูทำอะไรได้บ้างWhat Moo can do

  • อ่านสลิปได้ 20 แอปReads slips from 20 apps

    K PLUS, SCB EASY, Krungthai NEXT, MAKE, TrueMoney, Dime! และอีกเพียบ อ่าน QR และข้อความภาษาไทยด้วย OCR ในเครื่อง

    K PLUS, SCB EASY, Krungthai NEXT, MAKE, TrueMoney, Dime! and more. It reads the slip QR and the Thai text with on-device OCR.

  • แยกหมวดให้เองSorts itself

    มีกฎร้านค้าไทยและอังกฤษในตัว 247 ข้อ ตั้งแต่ 7-Eleven ถึง BTS แก้หมวดครั้งเดียว มูจำไว้ใช้ครั้งหน้า

    247 built-in merchant rules, from 7-Eleven to BTS. Fix a category once and Moo remembers it next time.

  • รู้ว่าโอนเข้าบัญชีตัวเองSpots your own transfers

    ย้ายเงินข้ามธนาคารของตัวเองไม่ใช่รายจ่าย มูดูออกและไม่นับซ้ำ

    Moving money between your own banks isn't spending. Moo can tell, and doesn't count it twice.

  • สรุป เทียบ และตั้งงบSummaries & budgets

    โดนัทแยกตามหมวดหรือแท็ก เทียบย้อนหลัง 6 เดือน และงบที่บอกว่ายังใช้ได้อีกวันละเท่าไหร่

    A donut by category or tag, a 6-month comparison, and budgets that tell you what you can still spend per day.

  • นำเข้าบิลบัตรเครดิตCredit card statements

    นำเข้า e-Statement PDF ที่ล็อกรหัสไว้ได้ ทั้ง KBank, SCB, KTC, Krungsri, BBL, ttb, UOB และ AEON

    Import password-protected PDF e-statements from KBank, SCB, KTC, Krungsri, BBL, ttb, UOB and AEON.

  • ข้อมูลเป็นของคุณYour data, your way

    ส่งออก CSV หรือ JSON ได้ตลอด ใช้ได้ทั้งไทยและอังกฤษ เลือกธีมชมพูหรือดำส้ม

    Export to CSV or JSON any time. Thai or English, pink or black and orange.

คำถามที่พบบ่อยQuestions

MooJot เปลี่ยนชื่อเป็นอะไร?What happened to MooJot?

MooJot เปลี่ยนชื่อเป็น OpenJot แล้ว เป็นแอปเดิมโดย Trajectonomics กับมูตัวเดิม ติดตั้งเวอร์ชันใหม่ทับ MooJot แล้วรายการของคุณยังอยู่ครบ

MooJot is now OpenJot, the same app by Trajectonomics with the same Moo. Installing the new version over MooJot keeps every record.

ติดตั้งนอก Play Store ปลอดภัยไหม?Is installing outside the Play Store safe?

ไฟล์ APK สร้างโดย GitHub Actions จากซอร์สโค้ดสาธารณะ เซ็นด้วยคีย์ของโปรเจกต์ และมี SHA256SUMS ให้ตรวจ คุณเปิดอ่านโค้ดได้ทุกบรรทัด

ใบรับรองของคีย์คือ CN=MooJot ซึ่งเป็นชื่อเดิมของแอป ลายนิ้วมือ SHA-256 be15a0f5b17358990cecde23d3c49dc02a1741ee544006ac5b0114755041a3a1 ทุกเวอร์ชันต่อจากนี้เซ็นด้วยคีย์เดียวกันนี้ ถ้าลายนิ้วมือไม่ตรง อย่าติดตั้ง สายเทคนิคตรวจเองได้ด้วย apksigner verify --print-certs openjot-android-arm64.apk

The APK is built by GitHub Actions from the public source code, signed with the project's key, and published with SHA-256 checksums. You can read every line of the code.

The key's certificate carries the app's earlier name, CN=MooJot; its SHA-256 fingerprint is be15a0f5b17358990cecde23d3c49dc02a1741ee544006ac5b0114755041a3a1. Every future release is signed with this same key, so if the fingerprint differs, don't install it. To check it yourself: apksigner verify --print-certs openjot-android-arm64.apk

ใช้กับ iPhone ได้ไหม?Does it work on iPhone?

ยังไม่ได้ ตอนนี้มีเฉพาะ Android 7.0 ขึ้นไปที่เป็นมือถือ 64 บิต (มือถือเกือบทุกรุ่นที่ขายตั้งแต่ราวปี 2017 เป็น 64 บิต)

Not yet. OpenJot is Android-only for now: Android 7.0 or newer on a 64-bit phone. Nearly every phone sold since about 2017 is 64-bit.

ต้องต่ออินเทอร์เน็ตไหม?Does it need the internet?

ไม่ต้อง การอ่านสลิป OCR และการแยกหมวดทำในเครื่องทั้งหมด เมื่อต่อเน็ตอยู่ ML Kit ของ Google ที่ช่วยอ่านภาษาอังกฤษบนสลิปจะส่งสถิติการใช้งาน เช่น รุ่นมือถือและเวอร์ชันแอป ให้ Google (ไม่ส่งรูปหรือข้อความในสลิป) และถ้าคุณเลือกเปิดส่งสถิติการใช้งานแบบไม่ระบุตัวตน (ไม่มีรายการหรือยอดเงิน) แอปจะส่งตอนต่อเน็ตเช่นกัน

No. Slip reading, OCR and categories all run on the phone. When you're online, Google's ML Kit, which reads the English text on slips, sends Google usage stats such as your phone model and the app version, never the photo or its text. If you choose to share anonymous usage stats (never your records or amounts), the app also sends them when you're online.

เสียเงินไหม?Does it cost anything?

ไม่เสียเลย ไม่มีโฆษณา ไม่มีแพ็กเกจรายเดือน และเป็นโอเพนซอร์สภายใต้สัญญาอนุญาต MIT

No. There are no ads and no subscription, and it's open source under the MIT license.

OpenJot ต่างจากเหมียวจด (MeowJot) ยังไง?How is OpenJot different from MeowJot?

อ่านสลิปธนาคารไทยได้เหมือนกัน แต่ OpenJot ฟรีและเป็นโอเพนซอร์ส ไม่ต้องสมัคร งบประมาณ แท็ก นำเข้าบิลบัตรเครดิต และส่งออก CSV ใช้ฟรีหมด ส่วนเหมียวจดต้องสมัครด้วยเบอร์มือถือ และงบประมาณ แท็กเพิ่ม บิลบัตรเครดิต และ CSV อยู่ในแพ็กเกจเสียเงิน แต่ใช้บน iPhone ได้ ดูตารางเทียบเต็มๆ

Both read Thai bank slips. OpenJot is free and open source with no sign-up, and budgets, tags, credit card statement import and CSV export are all free. MeowJot signs you up with your phone number and puts budgets, more tags, credit card import and CSV export in paid plans, but it does run on iPhone. See the full comparison
