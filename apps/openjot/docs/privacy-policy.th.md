# นโยบายความเป็นส่วนตัวของ OpenJot

ฉบับแปลภาษาไทยนี้จัดทำเพื่อความสะดวกในการอ่าน หากข้อความไม่ตรงกับฉบับภาษาอังกฤษ ให้ถือฉบับภาษาอังกฤษเป็นหลัก ([อ่านฉบับภาษาอังกฤษบน GitHub](https://github.com/trajectonomics/trajectonomics/blob/main/apps/openjot/docs/privacy-policy.md))

**อัปเดตล่าสุด: 25 พฤศจิกายน 2026**

Trajectonomics เป็นผู้เผยแพร่ OpenJot (ชื่อเดิม MooJot) แอปจดรายรับรายจ่ายส่วนตัว นโยบายนี้บอกว่าแอป Android และเว็บไซต์ที่ <https://openjot.trajectonomics.com> ทำอะไรกับข้อมูลบ้าง ข้อความเดียวกันนี้แสดงอยู่ในแอปที่ มูของฉัน → เกี่ยวกับ → นโยบายความเป็นส่วนตัว

สรุปสั้น ๆ: บัญชีรายรับรายจ่ายของคุณอยู่ในมือถือของคุณ Trajectonomics ไม่มีเซิร์ฟเวอร์บัญชีและไม่ได้รับรายการของคุณ OpenJot ไม่ส่งอะไรมาให้เราเกี่ยวกับวิธีที่คุณใช้แอป เว้นแต่คุณเลือกส่งสถิติการใช้งานแบบไม่ระบุตัวตน (คือหน้าจอและฟีเจอร์ที่ถูกใช้ ไม่มีรายการ ยอดเงิน หรือสลิปของคุณเด็ดขาด) ตัวสวิตช์นี้ปิดอยู่จนกว่าคุณจะเปิดเอง นอกจากนี้ เพื่ออ่านข้อความภาษาอังกฤษบนสลิป แอปใช้ Google ML Kit ซึ่งอ่านรูปภาพบนมือถือ แต่จะส่งตัวชี้วัดเกี่ยวกับประสิทธิภาพและการใช้งานของตัวมันเองไปให้ Google เช่น รุ่นของอุปกรณ์และรหัสประจำการติดตั้งแต่ละครั้ง OpenJot ปิดการส่งนี้ไม่ได้ หัวข้อ "ตัวชี้วัดของ Google ML Kit" ด้านล่างระบุว่าส่งอะไรบ้าง เว็บไซต์ใช้คุกกี้ก็ต่อเมื่อคุณอนุญาตเท่านั้น การอัปโหลดรูปสลิปเพียงทางเดียวที่โค้ดทำได้เป็นทางเลือก และจะเกิดขึ้นก็ต่อเมื่อมีคีย์ API ของ AksonOCR เก็บอยู่ในฐานข้อมูลบนเครื่องแล้วเท่านั้น หน้าการตั้งค่าไม่ได้ขอคีย์นี้จากคุณ

นโยบายนี้เขียนให้คนทั่วไปอ่านเข้าใจได้ เป็นคำอธิบายของโครงการเองว่าแอปทำงานอย่างไร ไม่ใช่หนังสือรับรองว่าปฏิบัติถูกต้องตามกฎหมาย และไม่ใช่คำแนะนำทางกฎหมาย

## ข้อมูลที่อยู่บนมือถือ

OpenJot เก็บข้อมูลต่อไปนี้ไว้ในไฟล์ส่วนตัวของแอป ข้อมูลเหล่านี้จะไม่ถูกส่งไปที่เซิร์ฟเวอร์ของ OpenJot ยกเว้นรหัสสุ่มสำหรับสถิติการใช้งานและเหตุการณ์ที่อธิบายไว้ใน "สถิติการใช้งานแบบไม่ระบุตัวตน" หากคุณเปิดสวิตช์นั้น

| ข้อมูล | เก็บที่ไหน | เก็บไปทำไม |
| --- | --- | --- |
| รายการรายรับและรายจ่าย: จำนวนเงินเป็นสตางค์ สกุลเงิน วันที่ เวลา บัญชี หมวดหมู่ ผู้รับเงิน บันทึก ป้ายกำกับ แหล่งที่มา | SQLite บนมือถือ | บัญชีรายรับรายจ่ายของคุณ |
| งบประมาณ กฎรายการที่เกิดซ้ำ หมวดหมู่ ป้ายกำกับ และรายชื่อธนาคารที่คุณเปิดใช้ | SQLite บนมือถือ | หมวดหมู่ วงเงิน และอัลบั้มที่จะสแกน |
| รูปสลิป เนื้อหา QR ข้อความที่อ่านได้ และค่าแฮชของรูป | พื้นที่เก็บข้อมูลส่วนตัวของแอปและ SQLite | แนบสลิปที่คุณนำเข้า |
| ข้อความที่ดึงจากไฟล์ PDF ใบแจ้งยอดบัตรเครดิต | SQLite ในรูปของรายการ | นำเข้าใบแจ้งยอดที่คุณเลือก |
| รหัสผ่านของไฟล์ PDF | หน่วยความจำของมือถือ เฉพาะระหว่างการนำเข้านั้น | เปิดไฟล์ ไม่ถูกเขียนลงฐานข้อมูล |
| ชื่อเจ้าของที่คุณพิมพ์ ภาษา วันเริ่มต้นเดือน วันเริ่มต้นสัปดาห์ สวิตช์อัลบั้มแชร์ | SQLite บนมือถือ | แยกการโอนของคุณเองออกจากรายการอื่น และตั้งค่าปฏิทิน |
| คีย์ API และชื่อโมเดลของ AksonOCR หากมีคีย์อยู่ | SQLite บนมือถือ ในรูปข้อความธรรมดา | OCR บนคลาวด์ (ไม่บังคับ) คีย์ไม่ได้ถูกเข้ารหัสด้วยรหัสลับแยกของ OpenJot |
| รหัสของรูปที่สแกนไปแล้ว และเดือนที่สแกนไปแล้ว | SQLite บนมือถือ | ไม่ทำงานซ้ำ |
| จำนวนรายวันของสลิปที่ซิงก์และรายการที่จัดหมวดหมู่ | SQLite บนมือถือ | ตัวนับกิจกรรมบนเครื่อง ไม่ใช่บันทึกที่ส่งไปที่อื่น |
| ธีม (ชมพูหรือมืด) และมือที่ถนัด (ซ้ายหรือขวา) | localStorage บนมือถือ | จำหน้าตาของแอป สองค่านี้ไม่ใช่คุกกี้ติดตามตัว |
| สวิตช์สถิติการใช้งาน และเมื่อเปิดอยู่ จะมีรหัสสุ่มไม่ระบุตัวตนและคิวของเหตุการณ์ที่ยังไม่ได้ส่ง | localStorage บนมือถือ | จำตัวเลือกของคุณ และส่งสถิติตามที่อธิบายไว้ด้านล่าง |

รูปสลิปและรายการในใบแจ้งยอดอาจมีชื่อ รายละเอียดบัญชี ยอดเงิน และข้อมูลส่วนบุคคลอื่นที่ได้รับความคุ้มครองตามพ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 (PDPA) ของประเทศไทย ด้วยเหตุนี้ข้อมูลจึงอยู่ในพื้นที่เก็บข้อมูลส่วนตัวของแอป เว้นแต่คุณส่งออก หรือเปิดคีย์ OCR ทางเลือกที่อธิบายไว้ด้านล่าง

## ข้อมูลเข้ามาอยู่ในแอปได้อย่างไร

คุณพิมพ์รายการเอง สแกนอัลบั้มของธนาคาร เลือกรูปหนึ่งรูป หรือเลือกไฟล์ PDF ใบแจ้งยอด นอกจากนี้แอปยังอ่านอัลบั้มที่คุณเปิดใช้ได้ โดยใช้สิทธิ์เข้าถึงรูปภาพของ Android (`READ_MEDIA_IMAGES` และ `READ_MEDIA_VISUAL_USER_SELECTED` บน Android 14 ขึ้นไป) บน Android รุ่นเก่า ไฟล์ manifest ยังประกาศ `READ_EXTERNAL_STORAGE` ซึ่งใช้เฉพาะกับรุ่นเก่าเหล่านั้น

คุณนำเข้าสลิปหนึ่งใบหรือ PDF หนึ่งไฟล์ด้วยตัวเลือกไฟล์ของระบบ โดยไม่ต้องให้สิทธิ์เข้าถึงอัลบั้มก็ได้ อัลบั้มแชร์ปิดอยู่จนกว่าคุณจะเปิดเอง ตัวสแกนจะมองหา QR ของสลิปก่อนจะถือว่ารูปนั้นเป็นสลิป โฟลเดอร์กล้องและโฟลเดอร์ภาพหน้าจอไม่ใช่เป้าหมายของการสแกน

เครื่องมือบนเครื่องอ่านสลิปในมือถือโดยตรง ได้แก่ ตัวถอดรหัส QR, ML Kit Latin สำหรับข้อความภาษาอังกฤษ และ AksonOCR-Lite (โมเดล ONNX) สำหรับข้อความภาษาไทย ตามการออกแบบของ OpenJot ขั้นตอนเหล่านี้ไม่ส่งรูปให้ Trajectonomics หรือ Google อย่างไรก็ตาม ML Kit ส่งตัวชี้วัดเกี่ยวกับการทำงานของตัวเองให้ Google ซึ่งอธิบายไว้ในหัวข้อถัดไป

ไฟล์ manifest ประกาศ `INTERNET` เพื่อให้ ML Kit ส่งตัวชี้วัดเหล่านั้นได้ และเพื่อให้คำขอ OCR ทางเลือกด้านล่างกับสถิติการใช้งานแบบไม่ระบุตัวตน (ทางเลือกเช่นกัน) ใช้ HTTPS ได้ ไฟล์ manifest ยังประกาศ `POST_NOTIFICATIONS` ด้วย แอปรุ่นปัจจุบันไม่ส่งเนื้อหาการแจ้งเตือนไปที่ใด และไม่ใช้การแจ้งเตือนเพื่อเก็บข้อมูล

## ตัวชี้วัดของ Google ML Kit

OpenJot ใช้ระบบจดจำข้อความของ Google ML Kit เพื่ออ่านข้อความภาษาอังกฤษบนสลิป ML Kit เป็นไลบรารีที่ Google สร้างขึ้น ไม่ใช่โอเพนซอร์ส และอยู่ภายใต้ข้อกำหนดการให้บริการ ML Kit ของ Google: <https://developers.google.com/ml-kit/terms>

ML Kit อ่านรูปภาพบนมือถือ Google ระบุว่า ML Kit ไม่ส่งรูปภาพหรือข้อความที่อ่านได้ไปยังเซิร์ฟเวอร์ของ Google แต่ส่งตัวชี้วัดเกี่ยวกับประสิทธิภาพและการใช้งาน ML Kit ในแอปให้ Google เอกสารเปิดเผยข้อมูลของ ML Kit จาก Google (<https://developers.google.com/ml-kit/android-data-disclosure>) ระบุข้อมูลประเภทเหล่านี้:

- ข้อมูลอุปกรณ์ เช่น ผู้ผลิต รุ่น เวอร์ชัน Android และบิลด์
- ข้อมูลแอป ได้แก่ ชื่อแพ็กเกจและเวอร์ชันของแอป
- รหัสประจำการติดตั้งแต่ละครั้ง ซึ่ง Google ระบุว่าไม่ได้มีไว้เพื่อระบุตัวผู้ใช้หรือตัวเครื่อง
- ตัวชี้วัดด้านประสิทธิภาพ เช่น การจดจำข้อความใช้เวลานานเท่าไร
- การตั้งค่า API เช่น รูปแบบและความละเอียดของรูปภาพ และขนาดของข้อมูลเข้าและข้อมูลออก
- เวอร์ชันของฟีเจอร์ ML Kit ประเภทของเหตุการณ์ (เช่น การเริ่มต้นระบบ การจดจำข้อความหนึ่งครั้ง หรือการปล่อยทรัพยากร) และรหัสข้อผิดพลาด

Google ระบุว่า ML Kit ส่งข้อมูลนี้ผ่าน HTTPS ใช้เพื่อการวินิจฉัยและวิเคราะห์การใช้งาน และไม่ถ่ายโอนให้บุคคลที่สาม ข้อมูลนี้อยู่ภายใต้นโยบายความเป็นส่วนตัวของ Google (<https://policies.google.com/privacy>) Trajectonomics ไม่ได้รับตัวชี้วัดเหล่านี้และลบไม่ได้

OpenJot ไม่มีการตั้งค่าที่ปิดการส่งตัวชี้วัดเหล่านี้ และเอกสารของ Google ก็ไม่ได้อธิบายวิธีปิดไว้ สวิตช์ "ส่งสถิติการใช้งานแบบไม่ระบุตัวตน" ควบคุมเฉพาะสถิติของ OpenJot เอง ไม่ได้ควบคุม ML Kit ตัวอ่านข้อความของ ML Kit ทำงานเมื่อคุณสแกนอัลบั้มธนาคาร เลือกรูปสลิป แชร์สลิปมาที่ OpenJot หรืออ่านสลิปซ้ำ การพิมพ์รายการด้วยมือไม่ใช้ ML Kit

## การอัปโหลดไปยัง AksonOCR (ไม่บังคับ)

ก็ต่อเมื่อการตั้งค่าบนเครื่องมีคีย์ API ของ AksonOCR ที่ไม่ว่างเปล่า และสลิปนั้นยังต้องการข้อความภาษาไทย แอปจึงจะส่งรูปสลิปนั้นผ่าน HTTPS ไปที่ AksonOCR ที่ `https://backend.aksonocr.com/api/v2/ocr` ได้ รูปอาจมีรายละเอียดส่วนบุคคลและทางการเงินที่พิมพ์อยู่บนสลิป คีย์ API ถูกส่งไปพร้อมกับคำขอนั้นด้วย

เราไม่ได้ดำเนินการ AksonOCR และเราไม่ได้รับสำเนารูปกลับมาไว้ในเซิร์ฟเวอร์ของเรา AksonOCR เก็บอะไรไว้และเก็บนานแค่ไหนเป็นไปตามที่ AksonOCR กำหนด ไม่ใช่ตามนโยบายนี้ หากเว้นคีย์ไว้ว่าง คำขอนี้จะไม่ถูกส่ง การติดตั้งใหม่มีคีย์ว่างเปล่า

หน้ามูของฉันที่อธิบายเรื่อง OCR ในเครื่อง หมายถึงโมเดลบนเครื่อง หน้านั้นไม่ได้ปิดช่องทางทางเลือกนี้ หากมีคีย์อยู่ในฐานข้อมูลแล้ว

## สถิติการใช้งานแบบไม่ระบุตัวตน

เป็นทางเลือกและปิดไว้ตั้งแต่แรก ขั้นตอนความเป็นส่วนตัวในทัวร์ต้อนรับจะถามคุณ และสวิตช์ "ส่งสถิติการใช้งานแบบไม่ระบุตัวตน" ในมูของฉันเปลี่ยนได้ทุกเมื่อ จนกว่าคุณจะเปิด โค้ดที่ส่งสถิติจะไม่ถูกโหลดเลย และไม่มีอะไรถูกเก็บไว้เพื่อส่งทีหลัง หากคุณเปิด แอปจะส่งเหตุการณ์การใช้งานชุดเล็ก ๆ เพื่อให้เราเห็นว่าคนใช้ฟีเจอร์ไหนและติดขัดตรงไหน

เหตุการณ์หนึ่งรายการอาจมีสิ่งเหล่านี้:

- ชื่อของเหตุการณ์ เช่น คุณเปิดสถิติ แอปถูกเปิด มีการดูหน้าจอ มีการดูขั้นตอนของทัวร์ต้อนรับ อนุญาตหรือปฏิเสธการเข้าถึงรูปภาพ การสแกนสลิปเริ่ม เสร็จ หรือล้มเหลว มีการบันทึกหรือลบรายการ มีการนำเข้าใบแจ้งยอด มีการส่งออกข้อมูล หรือมีการเปลี่ยนการตั้งค่า
- สำหรับบางเหตุการณ์ จะมีป้ายสั้น ๆ หรือตัวเลข ได้แก่ ชื่อหน้าจอ ประเภทรายการ (รายจ่าย รายรับ หรือโอน) เป็นรายการใหม่หรือรายการที่เกิดซ้ำ จำนวนสลิปหรือรายการในใบแจ้งยอดที่นำเข้าหรือข้ามเพราะซ้ำ รูปแบบไฟล์ที่ส่งออก หรือค่าใหม่ของการตั้งค่าธีม มือที่ถนัด ภาษา หรือวันเริ่มต้นเดือน
- เวอร์ชันของแอป ภาษาและธีมของแอป และรายละเอียดทางเทคนิคที่ไลบรารีวิเคราะห์ข้อมูลเพิ่มเข้ามา เช่น เวอร์ชัน Android และ WebView ประเภทอุปกรณ์ ขนาดหน้าจอ และเขตเวลา
- รหัสสุ่มที่สร้างขึ้นบนมือถือ เพื่อให้นับเหตุการณ์จากการติดตั้งเดียวกันรวมกันได้ และรหัสเซสชัน

รายการเหตุการณ์และป้ายที่อนุญาตอยู่ในซอร์สโค้ดของแอป (`src/lib/analyticsEvents.ts`) และแอปจะทิ้งทุกอย่างที่ไม่อยู่ในรายการก่อนส่ง เหตุการณ์จะไม่มียอดเงิน ผู้รับเงิน บันทึก ชื่อหมวดหมู่ ป้ายกำกับ หรือบัญชี รูปสลิป ข้อความจาก OCR ชื่อไฟล์ หรือสิ่งที่คุณพิมพ์ เราไม่เชื่อมโยงรหัสสุ่มกับชื่อ อีเมล เบอร์โทรศัพท์ หรือรหัสโฆษณาของคุณ ไม่มีการบันทึกเซสชัน และไม่มีการจับภาพหน้าจออัตโนมัติ

เหตุการณ์ส่งผ่าน HTTPS ไปที่ `openjot.trajectonomics.com` หรือ `moojot.trajectonomics.com` สำหรับแอปเวอร์ชันก่อน 1.5.0 ทั้งสองโฮสต์ส่งต่อให้ PostHog ผู้ให้บริการวิเคราะห์ข้อมูลของเรา บน EU Cloud ของ PostHog PostHog ได้รับที่อยู่ IP ของการเชื่อมต่อและใช้ประมาณประเทศและเมืองของคุณ การปิดสวิตช์จะหยุดส่งทันทีและรีเซ็ตรหัสสุ่ม ดังนั้นหากเปิดอีกครั้ง แอปจะเริ่มด้วยรหัสใหม่ เพราะรหัสไม่ได้เชื่อมกับตัวคุณ เราจึงมักหาเหตุการณ์ในอดีตของคนใดคนหนึ่งไม่ได้ หากต้องการให้เราลองหา โปรดติดต่อผ่านลิงก์ติดต่อด้านล่าง

## เว็บไซต์

เว็บไซต์นับการคลิกลิงก์และการดาวน์โหลดแอปโดยไม่ใช้คุกกี้ สำหรับแต่ละครั้ง เซิร์ฟเวอร์ของเว็บไซต์บันทึกเพียงว่าการคลิกมาจากที่ไหน (เช่น โพสต์โซเชียลหรือลิงก์แคมเปญใด) ประเทศที่ผู้ให้บริการโฮสติ้งของเรา (Cloudflare) ระบุได้ แพลตฟอร์มแบบกว้าง ๆ (Android, iPhone, คอมพิวเตอร์ หรืออื่น ๆ) และเบราว์เซอร์ในแอปที่ใช้ (ถ้ามี) แล้วส่งไปที่ PostHog พร้อมรหัสสุ่มใหม่ทุกครั้ง จึงเชื่อมการคลิกเข้าด้วยกันไม่ได้ การนับเหล่านี้ไม่ส่งที่อยู่ IP หรือรายละเอียดเบราว์เซอร์ของคุณ

หากคุณแตะ "อนุญาต" บนแบนเนอร์คุกกี้ เว็บไซต์จะโหลดระบบวิเคราะห์เว็บของ PostHog จากโดเมนของตัวเองด้วย จากนั้น PostHog จะตั้งคุกกี้และใช้ local storage เพื่อนับการเข้าชมของคุณและดูว่าคุณใช้หน้าและปุ่มไหน และได้รับที่อยู่ IP ของคุณเพื่อประมาณตำแหน่ง หากคุณแตะ "ไม่อนุญาต" หรือไม่สนใจแบนเนอร์ สิ่งเหล่านี้จะไม่ถูกโหลดเลย คุณเปลี่ยนใจได้ทุกเมื่อด้วย "ตั้งค่าคุกกี้" ที่ด้านล่างของหน้า การเลือกไม่อนุญาตอีกครั้งจะลบคุกกี้และข้อมูลที่เก็บของ PostHog

เว็บไซต์จำภาษาและตัวเลือกคุกกี้ของคุณไว้ใน local storage

## สิ่งที่เราไม่เก็บ

เราไม่เก็บ:

- บัญชี OpenJot อีเมล หรือรหัสผ่าน
- บัตรชำระเงินให้ Trajectonomics (แอปใช้ฟรีและเราไม่รับเงิน)
- รหัสโฆษณาหรือรายงานการหยุดทำงาน (crash report)
- เหตุการณ์วิเคราะห์ข้อมูลใด ๆ ที่มีรายการ ยอดเงิน ผู้รับเงิน บันทึก หรือสลิปของคุณ
- รายชื่อผู้ติดต่อ ตำแหน่งที่ตั้ง หรือไมโครโฟนของคุณ
- บัญชีรายรับรายจ่าย ไม่ว่าด้วยการอัปโหลดอัตโนมัติแบบใด

Google ได้รับตัวชี้วัดของ ML Kit ที่อธิบายไว้ข้างต้น เราไม่ได้รับ

เราไม่ขายข้อมูลส่วนบุคคล เราไม่แบ่งปันข้อมูลส่วนบุคคลเพื่อโฆษณาข้ามบริบท (cross-context advertising) เราไม่ใช้รายการของคุณฝึกโมเดล

## เมื่อข้อมูลออกจากมือถือ

ข้อมูลออกจากมือถือเฉพาะกรณีเหล่านี้:

- คุณส่งออก CSV หรือ JSON หรือใช้เมนูแชร์ของ Android ไฟล์จะไปที่แอปที่คุณเลือก เราไม่ได้อัปโหลด
- ML Kit อ่านสลิป และส่งตัวชี้วัดที่อธิบายไว้ใน "ตัวชี้วัดของ Google ML Kit" ให้ Google ซึ่งไม่รวมรูปภาพและข้อความที่อ่านได้จากรูป
- คุณเก็บคีย์ API ของ AksonOCR ไว้ และแอปส่งรูปสลิปหนึ่งใบไปที่ AksonOCR ตามที่อธิบายไว้ข้างต้น
- คุณเปิดสถิติการใช้งาน และแอปส่งเหตุการณ์แบบไม่ระบุตัวตนที่อธิบายไว้ข้างต้น
- คุณส่งความคิดเห็นหรือคำถามถึงเราทางอีเมล แอปอีเมลของคุณจะส่งไปที่ support@trajectonomics.com เราได้รับที่อยู่อีเมลของคุณ ข้อความของคุณ และรายละเอียดที่แอปเพิ่มให้ (เวอร์ชันแอป เวอร์ชัน Android ภาษาของแอป) อีเมลถูกเก็บไว้ในกล่องจดหมายของเราซึ่งทำงานบน Cloudflare และผู้ช่วย AI ของกล่องจดหมายนั้นอาจอ่านอีเมลที่เข้ามาเพื่อช่วยร่างคำตอบ เราอาจสรุปสิ่งที่คุณเขียนโดยไม่ระบุชื่อหรืออีเมลของคุณ ไปไว้ใน issue สาธารณะบน GitHub
- คุณคัดลอกข้อความไปใส่ใน GitHub issue หรือรายงานความปลอดภัยด้วยตัวเอง อย่าใส่เลขบัญชีจริง รูปสลิป หรือบัญชีรายรับรายจ่ายทั้งหมดใน issue สาธารณะ

ธนาคาร Google (รวมถึง Google Play และ ML Kit) Android AksonOCR PostHog และ Cloudflare เป็นบุคคลที่สาม ข้อกำหนดของแต่ละรายใช้บังคับเมื่อคุณใช้บริการของเขา เราไม่รับผิดชอบต่อการล่มของบริการหรือแนวปฏิบัติด้านความเป็นส่วนตัวของบุคคลเหล่านั้น

## ข้อมูลอยู่นานแค่ไหน

รายการอยู่บนมือถือจนกว่าคุณจะลบ ล้างพื้นที่เก็บข้อมูลของแอป หรือถอนการติดตั้ง OpenJot โดยปกติ Android จะลบพื้นที่เก็บข้อมูลส่วนตัวของแอปเมื่อถอนการติดตั้ง ข้อมูลสำรองที่คุณทำไว้ หรือไฟล์ที่คุณส่งออก อยู่นอกแอปและจะอยู่ต่อไปจนกว่าคุณจะลบสำเนานั้น

เราไม่มีสำเนาบัญชีรายรับรายจ่ายบนเซิร์ฟเวอร์ ดังนั้นบัญชีจึงไม่มีระยะเวลาเก็บรักษาบนเซิร์ฟเวอร์ และเราก็ไม่มีข้อมูลสำรองบนเซิร์ฟเวอร์ที่จะกู้คืนให้คุณได้

สถิติการใช้งานและการนับจากเว็บไซต์ถูกเก็บไว้ใน PostHog นานเท่าที่แพ็กเกจ PostHog ของเราเก็บข้อมูล และเราอาจลบก่อนหน้านั้นได้

## ความปลอดภัย

ฐานข้อมูลอยู่ในพื้นที่เก็บข้อมูลส่วนตัวของแอป ซึ่งแอปอื่นไม่ควรอ่านได้ แต่นั่นไม่ใช่คำมั่นว่ามีการเข้ารหัสข้อมูลที่เก็บไว้

OpenJot มีล็อกแอปที่เลือกเปิดได้ (มูของฉัน → ล็อกแอป) ซึ่งปิดไว้จนกว่าคุณจะเปิดเอง เมื่อเปิดแล้ว แอปจะขอลายนิ้วมือ ใบหน้า หรือรหัสเครื่องตอนเปิดแอปและเมื่อออกไปนานกว่าหนึ่งนาที Android เป็นผู้แสดงหน้าขอยืนยันและตรวจสอบเอง OpenJot รู้เพียงว่าปลดล็อกสำเร็จหรือไม่ ลายนิ้วมือ ใบหน้า และรหัสของคุณไม่ถึง OpenJot เลย ล็อกนี้ปิดบังหน้าจอ แต่ไม่ได้เข้ารหัสฐานข้อมูล

ไม่มีวิธีเก็บข้อมูลใดปลอดภัยสมบูรณ์ ผู้ที่ปลดล็อกมือถือของคุณได้ หรือมีข้อมูลสำรองของมือถือ อาจอ่านฐานข้อมูลได้ หากคุณบันทึกคีย์ AksonOCR คีย์นั้นถูกเก็บในฐานข้อมูลนั้นเป็นข้อความธรรมดา

คำขอ OCR ทางเลือกและสถิติการใช้งานใช้ HTTPS รหัสผ่านของ PDF ใช้ในหน่วยความจำเพื่อถอดรหัสไฟล์และไม่ถูกบันทึก

## ตัวเลือกของคุณ

บนมือถือ คุณทำสิ่งเหล่านี้ได้:

- แก้ไขหรือลบรายการ
- เปิดหรือปิดธนาคารและอัลบั้มแชร์
- ปฏิเสธการเข้าถึงรูปภาพ แล้วใช้ตัวเลือกไฟล์แทน
- เปิดหรือปิดสถิติการใช้งานแบบไม่ระบุตัวตนในมูของฉัน
- ส่งออกสำเนา
- ถอนการติดตั้งแอปและลบพื้นที่เก็บข้อมูลส่วนตัวของแอป

เหล่านี้คือวิธีใช้งานจริงในการเข้าถึง แก้ไข และลบบัญชีรายรับรายจ่าย เราทำขั้นตอนเหล่านี้แทนคุณไม่ได้ เพราะเราไม่เคยได้รับข้อมูลนั้น

### ประเทศไทย (พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562)

หากพ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 (PDPA) ใช้กับคุณ ข้อมูลส่วนบุคคลในบัญชีรายรับรายจ่ายของ OpenJot ถูกประมวลผลบนอุปกรณ์ของคุณเพื่อบัญชีครัวเรือนของคุณเอง Trajectonomics ไม่ได้เก็บบัญชีนั้นเข้าระบบของตน สำหรับการส่งไปยัง AksonOCR ที่เป็นทางเลือก คุณเป็นผู้ทำให้เกิดการโอนข้อมูลด้วยการเก็บคีย์ไว้ และ AksonOCR เป็นผู้รับข้อมูล

นี่คือข้อมูลที่เราจัดการจริง เหตุผล และฐานทางกฎหมาย:

- **สถิติการใช้งานแบบไม่ระบุตัวตนจากแอป** (รหัสสุ่ม เหตุการณ์ที่ระบุไว้ข้างต้น และที่อยู่ IP ที่ PostHog เห็น): เพื่อดูว่าหน้าจอและฟีเจอร์ไหนถูกใช้ และคนติดขัดตรงไหน เพื่อให้เราปรับปรุงแอปได้ ฐานทางกฎหมาย: ความยินยอมของคุณ (มาตรา 19 แห่งพ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562) สวิตช์ปิดอยู่จนกว่าคุณจะเปิดเอง
- **คุกกี้วิเคราะห์ข้อมูลของเว็บไซต์** (คุกกี้ของ PostHog หน้าและปุ่มที่คุณใช้ และที่อยู่ IP ของคุณ): เพื่อดูว่าคนพบเว็บไซต์ได้อย่างไรและเว็บไซต์ใช้งานได้ดีหรือไม่ ฐานทางกฎหมาย: ความยินยอมของคุณ ซึ่งให้ไว้ด้วยการแตะ "อนุญาต" บนแบนเนอร์คุกกี้
- **การนับเว็บไซต์แบบไม่ใช้คุกกี้** (แหล่งที่มาของลิงก์ ประเทศ แพลตฟอร์มแบบกว้าง ๆ เบราว์เซอร์ในแอป): เพื่อนับว่าลิงก์ไหนพาคนเข้ามา ไม่มีที่อยู่ IP รายละเอียดเบราว์เซอร์ หรือรหัสถาวร จึงไม่เชื่อมโยงกับตัวบุคคล ฐานทางกฎหมาย: ประโยชน์โดยชอบด้วยกฎหมายของเราในการรู้ว่าลิงก์ไหนได้ผล (มาตรา 24 (5))
- **ตัวชี้วัดของ ML Kit** ไปที่ Google เมื่อ ML Kit อ่านสลิป ตามที่อธิบายไว้ใน "ตัวชี้วัดของ Google ML Kit" ตัวชี้วัดเป็นส่วนหนึ่งของการอ่านสลิปที่คุณสั่งให้แอปทำ (มาตรา 24 (3)) และ Google ใช้เพื่อการวินิจฉัยและวิเคราะห์การใช้งานตามนโยบายความเป็นส่วนตัวของ Google เอง หากต้องการหลีกเลี่ยง ให้พิมพ์รายการด้วยมือแทนการสแกน

สำหรับข้อมูลที่เราจัดการ คุณมีสิทธิเหล่านี้ตามพ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562:

- ถอนความยินยอมได้ทุกเมื่อ: สวิตช์ในมูของฉันสำหรับแอป และ "ตั้งค่าคุกกี้" บนเว็บไซต์ การถอนความยินยอมไม่ทำให้การประมวลผลที่เกิดขึ้นก่อนหน้านั้นเป็นอันเสียไป
- ขอเข้าถึงและขอรับสำเนาข้อมูลของคุณ และขอให้บอกว่าเราได้ข้อมูลมาอย่างไร
- ขอรับข้อมูลของคุณในรูปแบบที่อ่านได้และใช้กันทั่วไป หรือขอให้เราส่งให้ผู้อื่น
- คัดค้านการที่เราใช้ข้อมูลนั้น
- ขอให้เราลบ ทำลาย หรือทำให้ข้อมูลไม่สามารถระบุตัวบุคคลได้
- ขอให้เราระงับการใช้ข้อมูล
- ขอให้เราแก้ไขข้อมูลให้ถูกต้อง
- ร้องเรียนต่อสำนักงานคณะกรรมการคุ้มครองข้อมูลส่วนบุคคล (สคส.): <https://www.pdpc.or.th>

สถิติการใช้งานเชื่อมโยงกับรหัสสุ่มเท่านั้น ซึ่งเราไม่สามารถโยงมาที่คุณได้ จึงอาจหาเหตุการณ์ของคุณไม่พบ แต่เราจะลองหาหากคุณขอผ่านลิงก์ติดต่อด้านล่าง สำหรับคำขอให้ลบข้อมูลที่เราไม่ได้เก็บ เราตอบได้เพียงชี้ให้คุณกลับไปที่แอป ขั้นตอนถอนการติดตั้ง และ AksonOCR หากคุณใช้

**การส่งข้อมูลออกนอกประเทศไทย** PostHog เก็บสถิติการใช้งานและข้อมูลวิเคราะห์เว็บไซต์บน EU Cloud ในสหภาพยุโรป ซึ่งมี GDPR คุ้มครองข้อมูลส่วนบุคคล การเปิดสถิติการใช้งาน หรือการแตะ "อนุญาต" บนแบนเนอร์คุกกี้ ถือเป็นการให้ความยินยอมต่อการโอนข้อมูลนั้นด้วย Cloudflare ซึ่งให้บริการเว็บไซต์และส่งเหตุการณ์ต่อให้ PostHog จัดการคำขอในศูนย์ข้อมูลทั่วโลก Google อาจประมวลผลตัวชี้วัดของ ML Kit ในสหรัฐอเมริกาและประเทศอื่น ภายใต้มาตรการคุ้มครองของ Google เอง

### เขตเศรษฐกิจยุโรป (EEA) และสหราชอาณาจักร

หากคุณใช้แอปจาก EEA หรือสหราชอาณาจักร ข้อเท็จจริงเดียวกันนี้ใช้เช่นกัน เราไม่ได้ดำเนินการเซิร์ฟเวอร์ที่เก็บบัญชีรายรับรายจ่ายของคุณ เราจึงไม่อยู่ในฐานะที่จะเป็นผู้ควบคุมข้อมูลของบัญชีนั้นจากระยะไกล ฐานทางกฎหมายสำหรับรูปภาพทางเลือกที่คุณส่งไปที่ AksonOCR คือขั้นตอนที่คุณทำเองด้วยการเก็บคีย์และสแกน คุณหยุดช่องทางนั้นได้ด้วยการล้างคีย์หรือปล่อยให้ว่าง สิทธิในการเข้าถึง แก้ไข ลบ และโอนย้ายข้อมูลของบัญชีรายรับรายจ่ายใช้ได้บนอุปกรณ์ รวมถึงด้วยการส่งออกและถอนการติดตั้ง สถิติการใช้งานแบบไม่ระบุตัวตนและการวิเคราะห์ข้อมูลเว็บไซต์ทำงานก็ต่อเมื่อคุณยินยอมเท่านั้น และคุณถอนความยินยอมได้ทุกเมื่อ: สวิตช์ในมูของฉันสำหรับแอป และ "ตั้งค่าคุกกี้" บนเว็บไซต์ PostHog ประมวลผลเหตุการณ์เหล่านั้นบน EU Cloud ของตน

เราไม่โอนบัญชีรายรับรายจ่ายของคุณออกนอกมือถือ ตัวชี้วัดของ ML Kit ไปที่ Google และคำขอ AksonOCR ที่เป็นทางเลือกไปที่ผู้ให้บริการรายนั้น แต่ละรายอาจประมวลผลข้อมูลในประเทศใดก็ได้ที่ตนใช้ ภายใต้มาตรการคุ้มครองของตนเอง

### แคลิฟอร์เนีย

เราไม่ขายข้อมูลส่วนบุคคลและไม่แบ่งปันเพื่อการโฆษณาตามพฤติกรรมข้ามบริบท เราไม่เสนอสิ่งตอบแทนทางการเงินเพื่อแลกกับข้อมูลส่วนบุคคล ประเภทข้อมูลที่อาจมีอยู่บนอุปกรณ์ ได้แก่ ตัวระบุในสลิป (เช่น ชื่อหรือเลขอ้างอิงบัญชี) ข้อมูลทางการเงินที่คุณกรอก รูปภาพที่คุณนำเข้า และการตั้งค่าบนเครื่องที่ระบุไว้ข้างต้น เราไม่เก็บข้อมูลประเภทเหล่านี้เข้าเซิร์ฟเวอร์ของ OpenJot สถิติการใช้งานแบบไม่ระบุตัวตนและการนับจากเว็บไซต์ที่อธิบายไว้ข้างต้นเป็นข้อมูลกิจกรรมทางอินเทอร์เน็ต ส่งให้ PostHog ในฐานะผู้ให้บริการของเรา Google ได้รับตัวชี้วัดของ ML Kit ซึ่งรวมถึงรหัสประจำการติดตั้งแต่ละครั้ง ตามที่อธิบายไว้ข้างต้น

## เด็ก

OpenJot ไม่ได้มุ่งไปที่เด็กอายุต่ำกว่า 13 ปี และเราไม่จงใจเก็บข้อมูลส่วนบุคคลจากเด็กบนเซิร์ฟเวอร์ สถิติการใช้งานแบบไม่ระบุตัวตนไม่ได้เชื่อมโยงกับตัวบุคคล หากคุณอายุต่ำกว่า 20 ปี ให้ขอความยินยอมจากผู้ปกครองก่อนเปิดสถิติการใช้งานหรืออนุญาตคุกกี้บนเว็บไซต์ แอปไม่มีบัญชีที่เด็กจะมาลงทะเบียนกับเรา หากเด็กใช้มือถือที่ติดตั้งแอปไว้ รายการยังคงอยู่บนมือถือเครื่องนั้น
