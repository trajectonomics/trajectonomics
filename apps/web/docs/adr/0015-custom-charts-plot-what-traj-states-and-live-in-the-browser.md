# Custom charts plot what `traj` states, and live in the browser

People ask their own questions of the Snapshot: "income against spending and tax", "each Account's value". The Projection page lets a person pick some of the yearly figures `traj` already states and draw them together. A chart is a view, not a plan: it is kept in the browser, in no Scenario and not in the ledger, for the reason [ADR 0012](0012-the-tax-allowances-page-reads-what-traj-says-each-allowance-could-take.md) keeps view settings out of the Scenario. Every figure on screen is the CLI's string ([ADR 0002](0002-the-cli-is-the-only-source-of-figures.md)).

## Decision

- **Only stated series.** The catalogue (`src/lib/view/charts/`) is built from the projection runs the Snapshot already holds, with no new read, so `leaves.test.ts` and the Demo snapshot are unchanged. A series is one of: net worth at the close of the year (with the engine's real figure), each Account's value (`--accounts`, nominal and real, read on the roll-up ends), income, expenses, contributions, unfunded contributions, interest and withdrawals (the annual table), each cash-flow line by Flow and by category (`--breakdown`), each Levy's tax due and taxable income (`taxYears`), each spending rule's paid amount (nominal and real) and what heirs would receive (nominal and real). Marginal and effective rates (#404) and the account income, costs, routing and transfer totals (#409, #416) are not in the contract yet, so they are not offered and there is no second axis; each is a new id when its table lands. A chart of a what-if lens is not offered: the page draws the Snapshot's run.
- **No money arithmetic.** A point is the CLI's string; `toChartNumber` places its mark and the tooltip, the legend and the table show the string. A stacked chart stacks the placed numbers for drawing only (`stackSpans`): positives upward, negatives downward from zero. Nothing is summed, differenced or divided as a figure, and no total of a stack is shown.
- **Terms.** Net worth, Account values, a spending rule's paid amount and what heirs receive have a real figure from `traj`, so they follow the page's terms control (nominal, real, both). Every other series is drawn nominal and named "(nominal)" when the terms ask for real. A stacked chart draws one set of terms: "both" draws it nominal, and the chart says so.
- **Where a point sits.** On the x axis a point is at the calendar year its period ends in, read from the date's text. A roll-up that ends part-way into a year can end in the same year as the one before; the later period is placed just after the first and named by its month (`2028-12`), and none is dropped.
- **Storage.** `localStorage`, key `traj.charts`, one JSON document `{ "format": "trajectonomics-charts", "version": 1, "charts": [...] }`, each chart `{ id, name, kind, series }` with `kind` one of `line`, `bars`, `stacked-line`, `stacked-bars` and `series` the ids above (at most 8; at most 50 charts). It is keyed by series ids and not by plan, so a chart works on every plan. The document holds no figure. Every read and write is in `src/client/` (`charts.svelte.ts`) in a try/catch; with storage unavailable (a private window) the page still creates, shows, edits and deletes charts for the visit and says they are not kept, and that export keeps them. Text in storage that cannot be read is no charts, and the page says why. The `storage` event re-reads, so two tabs agree.
- **Export and import.** The same document is the exported file (`trajectonomics-charts.json`). An import is read strictly: anything that is not that document (not JSON, another format, a newer version, a kind or series list that does not fit) is refused whole with a sentence and changes nothing. A good file is added after the charts already held, each under an id not yet used; it is refused when the total would pass 50.
- **A Snapshot whose series no longer exist.** A chart that names a series the selected plan lacks (no tax, an Account that was removed, a rule that was deleted) draws what it can and lists each missing series by name with its reason ("this plan has no tax") above the chart; a chart with none of its series says so and draws nothing. It does not fail. In the drawer a chosen series that no plan lists is shown under "Not in this Snapshot" so it can be taken off.
- **The page.** The Projection chart's title is a native select (the net worth chart, "My charts", "New chart…"); the choice is the address bar's `chart`. "New chart" and Edit open the right-side drawer (name, kind, series by group; Create is enabled once one series is chosen, and an empty name takes the first series' name). Edit, Duplicate and Delete (after a question) sit beside the chart. A series the selected plan lacks is greyed out in the picker with its reason, and a group the plan has none of says so once. Each chart has a table of every plotted value as the text alternative (`details`, scrolling inside its own box, so the page does not scroll sideways), and the chart is a keyboard-operable slider as the other charts are. Hide amounts masks the table, the tooltip and the axis.
- **No chart library.** The charts use the existing line layout and a new `columnLayout` (bars, stacked bars, stacked line) in `src/lib/chart/`, drawn by the same SVG component with a four-token palette whose second round is told apart by dash or fade ([ADR 0003](0003-astro-with-react-islands-and-no-chart-library.md), kept by [ADR 0006](0006-svelte-5-on-sveltekit-replaces-astro-and-react.md)).

## Considered Options

- **A file next to the ledger.** Rejected: a second store for `traj` to own and back up, for a view.
- **Keying a chart by plan.** Rejected: a person's question ("income against tax") is the same on every plan.
- **A sum or ratio series ("savings rate").** Rejected: it is arithmetic on money (ADR 0002); `traj` would have to state it.

## Consequences

- A change in the shape of the stored document is a new `version`; an older page refuses a newer file instead of misreading it.
- `src/lib/view/charts/charts.test.ts` pins the catalogue, the greyed series and reasons, the round trip and the bad imports; `src/client/charts.svelte.test.ts` pins storage available and unavailable; `src/components/charts/charts.svelte.test.ts` renders a stacked-bars chart of income, expenses and tax on two plans and with amounts hidden.
