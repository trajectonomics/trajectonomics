---
title: ประมาณภาษีปี 2569 กับ AI agent ของคุณ
description: บอกเงินได้และค่าลดหย่อนปี 2569 ให้ agent ของคุณ แล้วให้ traj คำนวณภาษีเงินได้บุคคลธรรมดา ดูว่าต้องชำระเท่าไร และถ้าเพิ่มค่าลดหย่อนหนึ่งรายการผลจะเปลี่ยนไปอย่างไร
---

หน้านี้ใช้กับปีภาษี 2569 (ค.ศ. 2026) เท่านั้น agent ของคุณรวบรวมข้อมูล `traj` คำนวณภาษี และคุณตรวจผลกับแบบของกรมสรรพากรเอง ตัวเลขที่ได้เป็นเพียงการประมาณ ไม่ใช่แบบแสดงรายการภาษี

ตัวอย่างการรันจริงและผลลัพธ์อยู่ในหน้า [Estimate your 2026 tax with your agent](/cli/tax-season-2026/) (ภาษาอังกฤษ) หน้านี้แสดงเฉพาะคำสั่งโดยไม่มีผลลัพธ์

## สิ่งที่ควรบอก agent

สกิล `traj-plan` มีขั้นตอนคำนวณภาษีไทยที่พา agent ทำงานตามหน้านี้ และสกิลตั้งค่าเริ่มต้น (onboarding) จะติดตั้งให้เอง ลองบอก agent ว่า "ช่วยประมาณภาษีปี 2569 ของฉัน แล้วบอกว่าค่าลดหย่อนแต่ละรายการเปลี่ยนผลไปเท่าไร"

ก่อนให้ agent รันคำสั่งใด ให้บอกข้อมูลปี 2569 เหล่านี้:

- **เงินได้พึงประเมินแยกตามประเภท** เช่น เงินเดือน (มาตรา 40(1)) รายได้จากธุรกิจส่วนตัวหรืออาชีพอิสระ (เช่น มาตรา 40(2), 40(6) หรือ 40(8)) และรายได้อื่น ระบุเป็นยอดทั้งปี หน่วยเป็นบาท
- **ภาษีที่ถูกหัก ณ ที่จ่ายไปแล้ว** คือยอดที่นายจ้างหรือผู้จ่ายเงินหักไว้ตลอดปี 2569 `traj` บันทึกเป็นภาษีที่ชำระล่วงหน้า ผ่านแฟล็ก `--carry-in` ของ `traj projection` จึงหักออกจากยอดที่ยังต้องจ่าย
- **ค่าลดหย่อนที่คุณมี** เฉพาะที่เกี่ยวข้องกับคุณ:
  - เงินสมทบประกันสังคม (`--social-security`)
  - เบี้ยประกันชีวิต (`--life-insurance`)
  - เบี้ยประกันสุขภาพของตนเอง (`--health-insurance`) และของบิดามารดา (`--parent-health-insurance`)
  - ดอกเบี้ยเงินกู้ยืมเพื่อที่อยู่อาศัย (`--mortgage-interest`)
  - เงินบริจาคที่หักลดหย่อนได้สองเท่า (`--donation2x`) และหนึ่งเท่า (`--donation1x`)
  - บุตร (`--children`) บิดามารดาที่คุณอุปการะ (`--parents`) ผู้พิการที่คุณดูแล (`--disabled-care`) และสถานภาพการยื่น (`--filing-status`)
  - กองทุนเพื่อการเกษียณที่คุณจ่ายในปี 2569 เช่น RMF, SSF, กองทุนสำรองเลี้ยงชีพ, ประกันชีวิตแบบบำนาญ และ ThaiESG

กองทุนเพื่อการเกษียณและ ThaiESG ไม่ใช่แฟล็ก agent จะติดป้ายกำกับ (label) ให้รายการที่คุณจ่ายเข้ากองทุนนั้น เช่น `rmf=allowance.retirement.rmf` เพื่อให้ `traj` หักยอดที่จ่ายจริง

agent จะแปลงปี พ.ศ. ในเอกสารเป็นปีคริสต์ศักราช (พ.ศ. 2569 คือ ค.ศ. 2026) และจะถามคุณเมื่อข้อมูลไม่ครบ แทนการเดา

## สิ่งที่ traj คำนวณ

ขั้นแรก agent จะบันทึกเงินได้ของคุณเป็น Scenario ชื่อ `base` ตามตัวอย่างในหน้าภาษาอังกฤษ จากนั้นสั่งให้ `traj` บันทึกการคำนวณภาษีปี 2569 ไว้ใน Scenario นั้น ต้องระบุ `--label` ว่าเงินได้แต่ละรายการอยู่ในมาตราใดของมาตรา 40 เพราะ `traj` ไม่เดาให้

```bash
traj scenario tax base --tax th-2026 --label salary=income.section40_1 --label rmf=allowance.retirement.rmf --social-security 9000 --life-insurance 20000 --json
```

ผลลัพธ์บอกสองอย่าง:

- `allowances.stated` คือค่าลดหย่อนที่คุณระบุด้วยแฟล็กหรือป้ายกำกับ
- `allowances.notStated` คือค่าลดหย่อนที่ระบบรองรับแต่คุณไม่ได้ระบุ ผลการคำนวณจึงไม่รวมรายการเหล่านี้

หากไม่ใส่ `--json` คำสั่งจะแสดงข้อมูล Scenario ทั้งหมด และใส่ `--none` เพื่อลบการคำนวณภาษีออกจาก Scenario ได้

แฟล็กใช้ระบุยอดที่จ่ายจริง ส่วนเพดานค่าลดหย่อนตามกฎหมาย `traj` นำมาใช้เอง

ยอดที่ต้องชำระอ่านจาก `taxYears` ของ `traj projection run`:

```bash
traj projection run --scenario base --as-of 2026-01-01 --horizon 2026-12-31 --json
```

- `due` คือภาษีที่ปีนั้นต้องชำระหลังหักค่าลดหย่อน ก่อนหักภาษีที่ชำระไว้แล้ว
- `prepaid` คือภาษีที่ชำระไว้แล้ว เช่นที่ถูกหัก ณ ที่จ่ายตลอดปี
- `owed` คือ `due` ลบ `prepaid` ถ้าติดลบหมายถึงได้คืน
- `settled` เป็น true เมื่อวันกำหนดชำระ (`settlementDate` สำหรับปี 2026 คือ 2027-03-31) อยู่ในช่วงที่คำนวณ ถ้าเป็น false ภาษีจะแสดงเป็นยอดที่ต้องชำระ แต่ยังไม่ถูกรวมในตัวเลขของ Projection

ตัวเลขทุกตัวอิงกับวันที่ as-of และวันสิ้นสุด (horizon) ที่คุณกำหนด ให้อ่านควบคู่กับสองค่านี้เสมอ

## ถ้าเพิ่มค่าลดหย่อนหนึ่งรายการจะเปลี่ยนอะไร

`traj projection compare` เปรียบเทียบ Scenario กับ what-if ที่แก้ค่าหนึ่งค่า ใน Scenario ตัวอย่าง รายการ RMF เริ่มที่ 0 จึงเทียบกรณีไม่มี RMF กับกรณีมี RMF ได้ใน Scenario เดียวกัน ค่าที่ใส่ใน `--set` ต้องมีอยู่แล้วในไฟล์ Scenario และจำนวนเงินในไฟล์เก็บเป็นสตางค์ ดังนั้น 50,000 บาทคือ `5000000`

```bash
traj projection compare base --set flows.rmf.amount=5000000 --as-of 2026-01-01 --horizon 2026-12-31 --json
```

ในตัวอย่างสมมติ (เงินเดือน 85,000 บาทต่อเดือน) ค่า owed อยู่ที่ 81,200 บาท และเมื่อเพิ่ม RMF 50,000 บาทจะเหลือ 71,200 บาท ลดลง 10,000 บาท เพราะที่ระดับรายได้นี้ เงิน 50,000 บาทอยู่ในช่วงอัตราภาษี 20% นี่คือคำตอบว่า "ถ้าเพิ่มเงินจำนวนนี้จะเปลี่ยนอะไร" ไม่ใช่คำแนะนำให้ซื้อกองทุนใด

## สิ่งที่ traj ไม่ทำ

- **ไม่ยื่นแบบ และไม่ใช้ e-Filing** คุณต้องยื่นแบบ ภ.ง.ด.90 หรือ ภ.ง.ด.91 ที่ตรงกับประเภทเงินได้ของคุณด้วยตนเอง โดยใช้ตัวเลขที่ตรวจแล้ว
- **ไม่แนะนำกองทุนหรือการลงทุนใดทั้งสิ้น** การแนะนำกองทุนรายตัวในประเทศไทยถือเป็นการให้คำแนะนำการลงทุนซึ่งอยู่ภายใต้การกำกับดูแล `traj` ตอบได้เพียงว่าจำนวนเงินหนึ่งจะเปลี่ยนผลอย่างไร
- **ตัวเลขเป็นการประมาณ** ให้ตรวจกับแบบของกรมสรรพากรก่อนยื่นทุกครั้ง
- **รองรับปีภาษี 2569 เท่านั้น** ปีอื่นยังไม่ได้คำนวณ
- **หน่วยลงทุนที่ลดหย่อนภาษีได้มีกำหนดเวลา** หน่วยลงทุนเพื่อการเกษียณ (เช่น RMF) หรือ ThaiESG ที่ใช้ลดหย่อนภาษีปี 2569 ได้ ต้องทำรายการให้แล้วเสร็จภายในวันทำการสุดท้ายของเดือนธันวาคม และตรวจวันปิดรับคำสั่งซื้อกับบริษัทจัดการกองทุนของคุณ

## ข้อมูลอยู่ในเครื่องของคุณ

Scenario และ ledger อยู่ในโฟลเดอร์ข้อมูลของคุณ และ ledger ไม่ส่งข้อมูลออกนอกเครื่อง `traj` ไม่เรียกโมเดลภาษาเลย แต่ agent ของคุณต่างออกไป ข้อความที่คุณพิมพ์ให้ agent จะถูกส่งไปยังผู้ให้บริการโมเดลที่ agent นั้นใช้งาน ก่อนแชร์สลิปเงินเดือนหรือเลขบัตรประชาชน ให้อ่านนโยบายความเป็นส่วนตัวของบริการนั้นก่อน
