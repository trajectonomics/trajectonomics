```flow
Install -> traj init -> Add accounts: traj account add -> Record: traj tx add -> Net worth: 879.50 THB
```

`traj` keeps one double-entry ledger file and computes every answer; the Agent judges.

## Install

[Installation](/cli/installation/) lists the three channels. On Linux or macOS:

```bash
curl -fsSL \
  https://github.com/trajectonomics/trajectonomics/releases/latest/download/install.sh \
  | sh
```

## From an empty machine to a first balance

```bash exec
# create ~/.traj and an empty database
traj init

# an asset account, an expense account, and the equity account an opening balance needs
traj account add Cash --type asset --currency THB
traj account add Food --type expense --currency THB
traj account add Opening --type equity --currency THB

# fund Cash at the start of the record, then spend from it
traj tx add --opening --from Opening --to Cash --amount 1000.00 --date 2026-01-01
traj tx add --from Cash --to Food --amount 120.50 --date 2026-03-01
```

Then read every account's balance and net worth:

```bash exec
traj balance --as-of 2026-03-31
```

```text output
asOf: 2026-03-31
rows:
  - account:
      id: 01a1ff02-9448-70cc-9da9-0ba9dc6e0149
      name: Cash
    type: asset
    amount: 879.50
    currency: THB
  - account:
      id: 01a1ff02-94a2-737d-bee2-c44a350103a9
      name: Food
    type: expense
    amount: 120.50
    currency: THB
  - account:
      id: 01a1ff02-950a-7437-b8f6-07a7233cf17b
      name: Opening
    type: equity
    amount: -1000.00
    currency: THB
netWorth:
  - currency: THB
    amount: 879.50
```

`--type` and `--currency` are required when adding an account, and THB is the only currency this
release supports. `--as-of` is required on `balance`. Every date a command acts on is `YYYY-MM-DD`,
and it is always one you pass.

`traj tx add --opening` is how a ledger gets its first money: `--from` names the equity account the
amount posts against. Net worth is assets minus liabilities, `879.50` THB here; each account's id
is its own and differs on your machine. Without the
opening balance Cash holds `-120.50` THB, and [the Baseline](/cli/commands/baseline/) refuses
the ledger rather than state a negative asset.

## Where your data lives

`traj init` writes `~/.traj/traj.db`, or `$TRAJ_HOME/traj.db` when `TRAJ_HOME` is set. That one file
is the ledger, and until `traj init` has created it every command that reads or writes it fails
with `ledger_missing`. [Your data](/cli/data/) says what else is in the directory, what is safe to
delete, and how to back it up.

`traj` counts anonymous usage unless you turn it off. The first successful command prints one line on
stderr about it; [`traj telemetry`](/cli/commands/telemetry/) says what is sent and how to stop it.
