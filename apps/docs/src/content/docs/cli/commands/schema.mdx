---
title: schema
description: Describe the commands and the error registry.
---

`traj schema` describes the commands and the error registry. It is generated from the same
definitions that validate input. The error registry it prints is the one the JSON error envelope
reads.

```bash
traj schema              # List commands and every error code.
traj schema init --json  # Show the input and output of init.
```

See [Commands](/cli/commands/) for the global options, exit codes and error envelope.
